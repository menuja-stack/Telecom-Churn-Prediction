## 📌 Project Overview
Customer churn is a critical issue for telecommunications companies. This project creates a Machine Learning solution to predict which customers are at high risk of leaving the service. The final product is an interactive web application that allows non-technical users to input customer data and receive a risk assessment in real-time.

## 📊 The Data
**Source:** [Telco Customer Churn (Kaggle)](https://www.kaggle.com/blastchar/telco-customer-churn)  
**Size:** 7,043 Customer Records | 21 Features  
**Target:** `Churn` (Yes/No)

### Key Drivers Identified:
* **Contract Type:** Month-to-month customers are **X%** more likely to churn.
* **Internet Service:** Fiber Optic users show higher churn rates due to potential service quality/cost issues.
* **Tenure:** New customers (0-12 months) are the most vulnerable.
